### 2. [Сравнение MLP, CNN, LSTM на задаче идентификации экземпляра](./02-fruit-recognition)

**Стек:** R, Python

## Результаты

| Модель | Точность | Эпох | Параметры |
|--------|:--------:|:----:|:---------:|
| LSTM (спиральные патчи) | 100.0% | 51 | 1.59 млн |
| MLP | 99.9% | 42 | 1.60 млн |
| CNN | 99.1% | 29 | 1.60 млн |

**Архитектуры:**
- **MLP** — полносвязная сеть с уплощением изображения
- **CNN** — свёрточная сеть с пулингом
- **LSTM** — рекуррентная сеть с кастомным слоем `SpiralPatchify` (патчи по спирали от центра)

**Ключевой вывод:**
Все модели достигли ~100% точности, так как классы датасета содержат фото одного объекта с разных ракурсов. Модели решали задачу **идентификации экземпляра**, а не обобщения категории. Для реалистичной оценки необходимо **объектное разделение** данных (в тест попадают объекты, отсутствующие в обучении).
