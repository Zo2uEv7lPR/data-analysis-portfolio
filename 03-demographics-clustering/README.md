# 03-demographics-clustering ♥ ♥ Кластерный анализ стран по демографическим показателям: численность населения, уровень рождаемости и средняя продолжительность жизни. Проект реализует кластеризацию методом k-means с проверкой качества через метод локтя и коэффициент силуэта, а также визуализацию результатов, включая анимацию переходов стран между кластерами.

## Библиотеки 

Для анализа используются следующие пакеты R: 
- tidyverse — манипуляции с данными и визуализация
- ggplot2 — построение графиков
- factoextra — визуализация результатов кластеризации
- plotly — интерактивные графики
- tidyr — приведение данных к нужной форме
- fmsb — радарные диаграммы
- cluster — алгоритмы кластеризации и силуэт
- gganimate — анимация
- MASS — дополнительные методы и наборы данных
- broom — приведение результатов моделей к аккуратному виду
- patchwork — объединение нескольких графиков
- kableExtra — оформление таблиц

## Как запустить 
1. Скачайте три датасета с Kaggle или World Bank Data
2. Поместите CSV-файлы в папку data/
3. Откройте analysis.Rmd в RStudio
4. Нажмите Knit (Ctrl+Shift+K)
5. Получите обновлённый analysis.html со всеми графиками
  
Время выполнения: ~5-10 минут (без анимации). С анимацией gganimate — около 15-20 минут.

## Этапы анализа

1. Загрузка и предобработка данных — чтение трёх датасетов (население, рождаемость, продолжительность жизни), объединение в единую таблицу, очистка и стандартизация признаков.
2. Выбор числа кластеров — метод локтя (WSS) и средняя ширина силуэта для k от 2 до 10.
3. Кластеризация — k-means с фиксированным зерном (set.seed(123)) для воспроизводимости.
4. Характеристика кластеров — описание каждого кластера по основным показателям с оформленными таблицами (kableExtra).
5. Визуализация — страны в пространстве главных компонент (cluster_plot.png), профили кластеров (cluster_profiles.png), распределение скоростей изменения показателей (speed_distribution.png), прогноз (forecast.png) и анимация переходов между кластерами (cluster_transitions.gif).

## Результаты 

Страны сгруппированы в кластеры со схожими демографическими профилями. Для каждого кластера получены описательные таблицы и визуализации, все файлы сохранены в папку output/.
